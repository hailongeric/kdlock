## 改动和保留条件

固定 CPU MCS 发布每次采样、400 亿 TSC ticks 的 CPU 窗口，以及 25 亿 ticks 的单锁窗口。
CPU 热后，单锁计数严格大于目标才读取时钟并更新热值：32/128/1024 分别在第
33/129/1025 个有效样本检查；两个检查之间沿用缓存热值。候选独立定义 spin 阈值，
mutex 仍保持 CPU 每 1024 次、单锁第 33 次检查。未增加运行期选项。

事先采用保守保留条件：低线程有收益，且 c1/c16 的 8/20 线程中位数和最大吞吐均不低于
同期 32 基线。前后基线分别展示，不合并为六轮，不据三样本范围宣称统计显著或性能等价。
两个候选都未通过；不把小幅负差一概认定为确定的阈值因果，但证据不足以更换默认值。

## 为什么调计数没有解决少线程问题

| 阶段 | 32 | 128 / 1024 | 对少线程的含义 |
| --- | --- | --- | --- |
| caller 分流 | pin 后 C `if` 读取 CPU 热值 | 相同 | CPU 热后仍走宽 clobber 入口；单锁阈值不能省掉已经发生的 caller 成本 |
| CPU 升温 | 完整冷 CAS/pending/MCS，MCS 发布每次采时 | 相同 | 冷获取仍能自然升温；增加单锁阈值不减少 CPU MCS 采时 |
| 单锁准入 | 每 33 个有效样本采时 | 每 129 / 1025 个有效样本采时 | 降低单锁采时密度，也延迟升温/降温；固定窗口下频率门槛变高，但没有读取代理收益 |
| 未准入 | provider 走完整原生获取 | 更长的初始未准入区间 | 延后 ticket/continuation/JIT 路径，无法区分昂贵短批次和有收益长批次 |
| 准入后 | fast/pending；必要时 ticket、continuation、排队、combiner/JIT | 相同 | 准入后仍支付相同的逐请求成本，候选没有调整批次选择与执行协议 |
| 解锁 | 通用宽 clobber；字节 5 快速原生释放，否则 generic | 相同 | SP/IP/BP、owner/ACK 和退休规则不变 |

按有效单锁样本计算，128/1024 将单锁采时次数分别减少约 74.4%/96.8%；
这是源码推导的采样密度变化，不是实测总指令数或时钟成本下降。
CPU MCS 采样、精确地址查找、计数更新、caller clobber 与准入后的请求成本仍在。

3线程在所有阶段的累计正文/combiner均恰好为1.00，全部会话零 WW jump；4线程约2.00。
提高阈值后这种短批次没有消失，3/4线程 JIT 比例也没有明显受抑制。
8线程每次 combiner 约35–40个正文，20线程约778–809个，固定成本有更大摊销空间。
这些计数支持短批次成本的解释，但本轮没有 PMU/独立原生对照，不能据此算出盈亏平衡点。

20线程的 JIT 比例从前测 99.77% 降至 1024 候选的 98.79%，恢复后回到 99.79%。
若每CPU只经历一次升温，32→1024 增加的 992 个未准入样本/CPU，占每线程100000次的
约 0.992 个百分点，与观测方向和量级一致。这是冷前缀模型，不是逐次轨迹证明，
也不能将所有吞吐变化都归因于这一项。

频率本身不能代表收益：按本次前测 c1 中位吞吐/线程数粗算，3线程约0.56 M次/秒/CPU，
20线程约0.26 M次/秒/CPU；更划算的长批次并不意味着每CPU更高的获取频率。
这是平均速率推算，不代表每个CPU分布。进一步收紧时间窗口可能先挡住20线程，
因此本轮未叠加窗口修改。后续收益准入任务保留在[性能计划](../../../docs/PERFORMANCE_PLAN.md#p11-基于收益的新请求准入)。

## 验证、环境与恢复

四个阶段均在 recovery guest 的 ext4 副本 `/root/host_fs/kdlock` 构建和执行。
内核 `6.1.159-kdclobber2`，使用已捕获的 `mutex-clobber2-20260919` 基线；未改建内核。
`nokaslr`、voluntary 抢占、40 vCPU；QEMU vCPU 0..39 对应宿主CPU 0..39，前20个在NUMA0。
实际 monitor 输出确认 `pre_static_boot_20260915` 快照；开始和最终均核对空闲。
每会话重新加载 provider/workload，翻译发布完成并停止 daemon 后，单CPU预热48000次；
准备和预热不计时，其他CPU的冷前缀仍计入测量。`jit_timing=0`，保留正文计数。

每阶段命令相同，仅预先安装的候选和输出目录不同；均另有外层 SSH timeout：

  --kernel-source /root/linux-6.1.159-kdclobber2 \
